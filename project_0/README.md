## Описание проекта
Компьютер загадывает целое число от 1 до 100, и нам его нужно угадать. Подразумевается, что программа угадывает число с минимальным количеством попыток.

## Какой кейс решаем?
Нужно написать программу, которая угадывает число за минимальное число попыток.

**Условия соревнования:**
- Компьютер загадывает целое число от 1 до 100.
- Алгоритм учитывает информацию о том, больше ли случайное число или меньше нужного.

## Результаты
В ходе работы я написал алгоритм, который угадывает число в среднем за **101** попытку.
